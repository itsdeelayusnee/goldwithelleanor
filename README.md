# Gold with Elleanor — Live Gold Price + Saving Tracker

Ready to deploy to Vercel.

Features:
- Live Public Gold GAP 24K price in MYR
- Estimated BND conversion
- RM100 estimated grams
- Gold value calculator
- Gold Saving Tracker tab
- Progress bar, remaining grams, monthly estimated grams, and estimated months to target
- Saves tracker progress locally in the visitor's browser

Deploy the entire folder to Vercel so `/api/gold-price` can run.


## Live source indicator
The page now clearly shows **LIVE FROM PUBLIC GOLD** when the Vercel API successfully fetches the GAP 24K price, and displays the **Public Gold last-updated timestamp** from the source page. If live fetching fails, the status changes to **FALLBACK PRICE** so visitors can tell immediately.
